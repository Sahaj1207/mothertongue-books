# MotherTongue Books

Original, illustrated children's books written natively in a child's own language, starting with Telugu, Kannada and Marathi.

Children learn to read best in their mother tongue, but most of the world's languages have very few children's books. UNESCO estimates that around 40% of people worldwide don't have access to education in a language they understand.

Built during the Meta Global AI Developer Hackathon (Oct 27 – Nov 4, 2026). All code in this repository was written during the hackathon.
